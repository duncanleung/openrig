# Session distills

Pages here are written by the post-compact hook described in
`docs/reference/postcompact-wiki-distill.md`. A model distills a redacted restore map. Treat
every page as a lead, not a fact. Verify against the code before you act on it.

File name: `YYYY-MM-DD-<seat>-<attempt8>.md`. The hook never edits `wiki/index.md`. A seat links
useful pages from the index with `/wiki-update`.
